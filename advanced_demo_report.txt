Security Operations Center Incident Report

Date: 2026-05-24

Summary:
Multiple endpoints exhibited ransomware-like behavior following suspicious PowerShell execution and lateral movement activity across the internal network.

Observed Behaviors:
- Encoded PowerShell commands executed from explorer.exe
- Suspicious process lineage:
  explorer.exe -> powershell.exe -> cmd.exe
- tasksche.exe launched @WanaDecryptor@
- Shadow copies deleted using:
  vssadmin delete shadows
- WMIC used for remote execution
- rundll32.exe executed suspicious DLLs from AppData
- Multiple failed SMB authentications observed
- Beaconing detected to external IP:
  45.33.32.156
- Potential C2 communication over uncommon ports
- Suspicious DLL injection into:
  winlogon.exe
  csrss.exe
- Persistence established using scheduled tasks
- Signs of WannaCry ransomware encryption activity
- Possible lateral movement using SMB

MITRE ATT&CK Behaviors:
- T1059 PowerShell
- T1105 Ingress Tool Transfer
- T1055 Process Injection
- T1486 Data Encrypted for Impact
- T1021 Remote Services
- T1547 Boot or Logon Autostart Execution
- T1218 Signed Binary Proxy Execution

Severity:
CRITICAL

Recommendation:
Immediate containment and forensic triage required.
