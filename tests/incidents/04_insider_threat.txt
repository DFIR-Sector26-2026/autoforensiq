INCIDENT REPORT — IR-2025-0089
Date: 2025-02-17
Reported by: HR Security + IT Security
Severity: MEDIUM-HIGH

SUMMARY
Following the resignation of a senior engineer (J. Tran, employee ID E-4821) on February 14,
IT Security conducted a routine access audit. The audit revealed that between February 10–14,
J. Tran accessed and copied a substantial volume of proprietary source code and internal
technical documentation to a personal USB device, and later to a personal cloud storage account.
J. Tran's final day was February 14; access has since been revoked.

AFFECTED SYSTEMS
- DEVWS-TRAN (10.10.5.77) — employee workstation
- GITSERVER01 (10.10.1.20) — internal Git repository server
- SHAREPOINT01 (10.10.1.45) — internal documentation portal

AVAILABLE EVIDENCE
- Disk image of DEVWS-TRAN (tran_workstation.img)
- NTUSER.DAT registry hive from DEVWS-TRAN
- Windows Event Logs from DEVWS-TRAN (tran_events.evtx)
- Network PCAP from Feb 10–14 (insider_traffic.pcap)
